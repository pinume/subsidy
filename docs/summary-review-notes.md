# 汇总报表规则梳理

本轮先以 `国补上传情况汇总.xlsx` 的五个工作表为梳理范围，从第一张“汇总”开始。Q1至Q17已确认，三项调整已于2026-10-08实现并验证。下文“已读取的现状”及核对过程保留梳理时的历史描述；当前生效规则以本轮方案汇总和实施验收为准。

## 核对顺序

1. 汇总：输入范围、发生额和销售净数量、上传状态金额与笔数、差额、比率。
2. 品类品牌汇总：退货排除、状态来源、维度、金额与数量。
3. 审核失败明细：入选状态、审核终止保留方式、商品关联。
4. 异常回款明细：商户范围、粉色记录、金额及排序。
5. 异常发票明细：颜色、匹配单据号及排序。

## 已读取的现状

- `summary_data.rs::SummaryMetrics::calculate` 的发生额取全部销售用券明细的补贴额之和；发生笔数取数量之和，保留正负抵消。财务大类为数码的归数码，其余归家电电脑。此处不按退货备注或行底色排除。
- 品类品牌汇总与上述总表不同：`build_sales_matrix` 排除备注为退货-原单和退货-退单的记录。
- 报表共享读取 `data.rs` 仍在内存把审核终止改成审核失败；汇总金额空值按零处理，每条上传记录计一笔，不因沉底而排除。
- 因此，清洗后保留的未匹配审核终止仍会进入汇总审核失败笔数，并通过差额影响未上传笔数。这与已确认的“未匹配审核终止不计上传状态业务笔数”冲突，列为本轮待落实项，不重新要求用户确认该既定口径。
- 以上为代码读取事实。此前完整 CLI 成功只证明报表可生成，不证明汇总口径已完成本轮确认。

## 已确认决定

Q1：保留总表发生额与发生笔数规则。发生额取全部销售用券明细的补贴额之和，发生笔数取数量净和；财务大类为数码的归数码，其余归家电电脑。不提前排除退货原单、退单，以正负金额和数量自然抵消。

Q2：保留回款统计规则。家电电脑与数码分别取对应已上传明细中清洗后状态为已回款的记录；回款额累加补贴金额，回款笔数按每行一笔统计。源状态为审核终止但已实际匹配回款的记录纳入；仍为审核终止的记录不纳入。

Q3：保留审核通过未回款与待审核统计规则。分别从对应类别的已上传明细按清洗后状态纳入；金额累加补贴金额，笔数每行一笔。金额为空时按零参与求和，仍计一笔。这两类使用清洗阶段生成的估算补贴金额。

Q4：保留普通审核失败统计方式。只纳入清洗后状态为审核失败的上传记录；金额累加补贴金额，笔数每行一笔；金额为空按零但仍计一笔。未匹配回款的审核终止按既定决定排除出上传状态金额和笔数统计，不再并入审核失败。审核终止是否保留在审核失败明细工作表中，属于后续清单范围问题，尚未决定。

Q5：保留差额统计。未回款金额/笔数＝发生金额/净笔数－已回款金额/笔数；未上传金额/笔数＝未回款金额/笔数－审核通过未回款－待审核－审核失败。未上传不直接统计销售用券备注为未上传的记录。差额为负时原样保留，不自动归零。

Q6：保留现有金额比率公式。发生额占比＝该类发生额/总发生额；回款率＝该类已回款金额/该类发生额；综合回款率＝该类（已回款＋审核通过未回款）金额/该类发生额；未回款占比＝该类未回款金额/该类发生额；四种未回款状态占比各自除以该类未回款总额。合计比率按合计金额重新计算，不取两类比率平均。分母为零统一显示0%；发生额合计占比在总发生额非零时为100%，为零时改为0%。负数或超过100%的结果原样保留。

Q7：保留汇总工作表的单位与精度。金额以万元显示两位小数，笔数显示整数，比率以百分比显示两位小数。合计和比率使用元单位的原始汇总金额计算，不使用已显示舍入的万元值反算。

Q8：保留品类品牌汇总的输入及退货排除规则。只读取销售用券情况统计，备注精确为退货-原单或退货-退单的记录全部排除；其余按财务大类、品牌和备注状态汇总。此表与总表全量求净额的规则不同。

Q9：保留品类品牌汇总的状态及数值来源。状态取销售用券备注，展示已回款、审核通过未回款、待审核、审核失败、未上传五组；金额累加销售用券补贴额，数量累加销售用券数量，不改取已上传补贴金额或上传行数。因此本表已回款金额可与总表的实际回款金额不同。

Q10：保留品类品牌汇总的单位与零值显示。金额以元显示两位小数，数量显示整数；某状态金额和数量同时为零时两格均显示短横线；只有其中一个为零时两格均保留数值；负数原样保留。

## 本轮方案汇总

范围为 `国补上传情况汇总.xlsx` 的五个工作表。Q1至Q17已逐项确认，三项调整已完成实现。维持现有五张表、字段、布局及未明确调整的行为。本轮不自动扩展为财务统筹表的状态规则调整，工作区原有财务统筹任务改动保持原样。

本轮明确调整三项：

1. 未匹配实际回款的审核终止记录不再转换为审核失败，不计上传状态金额及笔数，不进入审核失败明细；源记录继续在已上传清洗明细底部保留。实际已匹配、清洗后状态为已回款的记录继续计入回款。销售用券原单与退单的数量仍保持1/-1，不单独清零。
2. 总发生额为零时，发生额合计占比显示0%，与其他分母为零的比率一致；总发生额非零时仍为100%。
3. 固定品牌排序补入冰箱海信（博世之后、海尔之前）和彩电华为（终端）（创维之后、海信之前）。实际汇总原本已经动态输出这两项，本次调整的是固定排序。

其余已确认保留的核心规则：

- 总表发生额及笔数取全量销售用券的补贴额与数量净和，家电电脑和数码分组；回款和三种待处理/失败状态取对应上传明细金额与行数。未回款、未上传继续差额计算，负数不归零。
- 品类品牌汇总排除退货原单/退单；状态、金额、数量均取销售用券，五种状态分列；金额单位元、数量整数、双零显示短横线；当前45个品类品牌组合已核对无遗漏。
- 失败明细保留家电电脑9列、数码10列及现有分区。家电商品名称按发票号匹配全部发票记录，再按名称升序空最后；数码保持输入顺序。
- 异常回款保留粉色与商户双重筛选、上传唯一商户号提取、24列及分区；参考号重复/单次/空值排序与单次浅黄标记保留。
- 异常发票只列黄色且非粉色记录，8列、按匹配单据号排序，全部保留。
